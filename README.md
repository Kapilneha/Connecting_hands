# ✋ Neon Aura AR – Hand Tracking Experience

An interactive browser-based Augmented Reality (AR) project that uses real-time hand tracking to generate neon visual effects, particles, and gesture-based interactions using your webcam.

# GO live : https://kapilneha.github.io/Connecting_hands/

## 🚀 Features

- Real-time hand tracking using MediaPipe
- Gesture detection (pinch, open hand, fist)
- Interactive particle effects
- Neon visual connections between fingers
- Multiple visual themes (Rainbow, Cyberpunk, Lava, Ocean, Galaxy)
- Audio feedback (ambient hum + gesture-triggered sound)
- HUD displaying FPS, hands detected, gestures, and spread

## 🛠️ Tech Stack

- HTML5 Canvas
- JavaScript (Vanilla JS)
- MediaPipe Hands API
- Web Audio API

## 🎮 How to Run

1. Clone or download the project  
2. Open the folder in VS Code  
3. Right-click on `index.html` and open with Live Server  
4. Allow camera access in your browser  
5. Click **"Enter Experience"** to start  

## 🧠 How It Works

- MediaPipe detects hand landmarks in real time  
- Finger positions are used to detect gestures like pinch and spread  
- Canvas API renders particles, neon effects, and animations  
- Audio changes dynamically based on hand movement and interaction  

## 🎯 Controls

- Pinch → Creates shockwave + sound effect  
- Move hands → Generates particles  
- Two hands → Creates dynamic neon connections  
- Theme buttons → Switch visual styles  

## ⚠️ Requirements

- Webcam access  
- Modern browser (Chrome recommended)  
- Good lighting for better hand tracking
